Scorify Golf · League management

Quick start guide

For league admins

Set up a league, run an event, and share results — in the order you'll do it.

Sign in at
scorifygolf.com/login
Email
Password
1 · Set up once
1
Add your courses
Courses → New course. Search by name or add manually; set tees, par and yardage.
2
Create a league
Leagues → New league. Set scoring format, entry fee, side games and league logo.
3
Add players to your roster
Players. Name, email and handicap index.
2 · Before each event
1
Create the event
League → + Event. Date, course, first tee time, 9 or 18 holes.
2
Share registration
Event → Players. Copy the registration link; assign flights and tees.
3
Set groups & pairings
Event → Groups. Auto-assign or drag players; this creates each group's scoring code.
4
Set the payout
Event → Payout → Setup. Prize amounts per place and side game.
5
Send details & print
Event → Print & share. Tournament details email, tee sheet, scorecards, cart & side game signs.
3 · Day of the event
1
Activate the event
Event → Overview → Activate event. Required before anyone can score.
2
Players score on their phones
Scan the cart sign QR code or enter the group code, then score hole by hole. No app or account needed.
3
Correct scores if needed
Event → Print & share → Edit scores.
4
Share the live leaderboard
Event page → Leaderboard. It updates as scores come in.
Tip: print cart signs from Event → Print & share — each group's sign shows its group code and starting hole.
4 · After the round
1
Check results
Event page → Leaderboard. Net and gross standings for every flight.
2
Enter side game winners
Event → Side Games. Closest to pin and long drive winners.
3
Review the payout
Event → Payout → Results. Confirm it balances to the pot.
4
Close the event
Event → Close event. Locks scores and posts final results.
5
Share results
Event → Print & share. Results email and result images.
