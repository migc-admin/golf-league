🚀 First-Time Setup Order
1
Add a Course
Courses → New Course. Search by name or add manually. Set holes, tees, par & yardage.
2
Create a League
Leagues → New League. Set scoring format, entry fee, and side games.
3
Create an Event
Inside a league → New Event. Set date, course, tee time, holes (9 or 18).
4
Add Players
Event → Players tab. Add from roster or create new. Enter handicap index.
5
Assign Groups
Event → Groups tab. Drag players into groups. Generate group codes.
📱 Day of Event — Scoring
Players score via phone — go to the event's public page, enter their group code, tap their name, and score hole-by-hole.
Admin can score manually — Event → Groups tab → click any group → Enter Scores.
Live leaderboard updates in real time as scores come in. Share the public URL with players.
Activate the event before scoring begins — Event → Overview → Start Event.
Tip: Print Cart Signs from the Pre/Post Round tab — each group gets a card with their code and hole assignments.
🏁 After the Round
View Results — Event → Leaderboard tab. Full standings with net & gross scores.
Calculate Payouts — Event → Payout tab. Enter prize amounts; system calculates who earns what.
Record side game winners — CTP, Long Drive, Skins winners entered in the Payout tab.
Print Assets — Pre/Post Round tab: Tee Sheet, Cart Signs, CTP/Side Game cards.
Complete the event — locks scores and posts final results to the public leaderboard.
🌐 Public Event Page
Every event has a shareable public URL — share it with players before the round.
Shows event details, schedule, competitions & side games, pairings, and live leaderboard link.
Players can upload photos from the round directly on the event page.
Your event URL format
scorifygolf.com / [org] / [league] / [event]
Registration: If online registration is enabled, players can register & pay directly from the public event page.
Questions? Contact your league administrator.
