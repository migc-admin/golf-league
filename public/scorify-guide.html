Scorify Golf — Admin Guide
Welcome to
Scorify Golf.
This guide walks you through everything you need to run your first event — from setting up a course to posting final results.

Step 1
Add Your Golf Course
Before creating any events, add the course you play at. Scorify uses course data to calculate handicaps, display hole info during scoring, and generate tee sheets.
1
⛳ Admin → Courses → New Course
Search for your course

Type your course name in the search bar. Scorify pulls data from a golf course database — if your course is listed, select it and the holes, par, yardage, slope, and rating will auto-populate.

If your course isn't in the database, click Create Manually to enter it yourself.

Tip: Search by city or partial name if the full name doesn't return results.
2
Choose number of holes

Select 18 holes (default) or 9 holes for a nine-hole course. This controls which holes appear during scoring and on print assets.

3
Is the course officially rated?

Toggle Yes if the course has an official USGA course rating and slope. This is needed for accurate handicap calculations.

Toggle No for unrated courses (executive courses, private layouts, etc.) — Slope, Rating, and Stroke Index are not required.

4
Review tee information

For each tee set (e.g. Blue, White, Red), confirm or enter:

Slope *Used to calculate course handicap. Typically between 55–155.
Rating *Expected score for a scratch golfer. Usually close to par.
Par per hole *Par for each individual hole (3, 4, or 5).
Yardage optionalDisplayed on the scorecard during scoring.
Stroke Index *Handicap stroke allocation per hole (1 = hardest).
5
Save the course
Click Save Course. It will now appear in your course list and be available when creating events.
Note: You can edit a course at any time. Changes apply to future events only — scores already recorded are not affected.
Step 2
Create a League
A league groups your events together for a season. Think of it as a container — all events, players, standings, and payouts belong to a league.
1
🏆 Admin → Leagues → New League
Name your league
Give it a clear name — players will see this on the public event page and scorecards. Examples: Friday Morning Golf, SGV9 Golf Club — Fall 2026.
2
Set the season year
Used to organize leagues by year and display on standings pages.
3
Choose a primary scoring format

This sets the default format for all events in the league. You can override it per event.

Net Stroke PlayGross score minus course handicap. Most common format.
Gross Stroke PlayRaw strokes, no handicap adjustment.
StablefordPoints per hole relative to net par. Higher = better.
NassauThree separate competitions: front 9, back 9, total.
Best Ball / Scramble / ShambleTeam formats. Best Ball uses each player's best score per hole.
4
Configure side games
Side games run alongside the main format and have their own payouts.
SkinsHole-by-hole competition. Low net score wins the skin. Ties carry over.
Closest to Pin (CTP)Tee shot closest to the hole on designated par-3s.
Long DriveLongest drive in the fairway on designated holes.
Low PuttsFewest total putts across the round.
Tip: You can also add custom competitions (e.g. "Closest to the Tree", "Longest Par 3") using the free-form field.
5
Set entry fee & payout places

Enter the entry fee per player. This is used to calculate total prize pools automatically based on the number of players.

Set Places to Pay (1st, 2nd, 3rd, etc.) for overall and flight standings. Set to 0 if no payouts for that format.

6
Upload a league logo (optional)
Your logo appears on the public event page, scorecards, and print assets. Recommended: square image, at least 200×200px.
Step 3
Create an Event
Events are individual rounds within a league. Each event has its own players, groups, scores, and payouts.
1
🏆 Admin → Leagues → [Your League] → New Event
Set the basics
Event Name optionalDefaults to "Event #1", "Event #2" etc. Add a name for special events.
Date *The date of the round.
Course *Select from your saved courses.
Tee Time optionalFirst tee time. Used to calculate group tee times automatically.
Holes Played *18 (default) or 9. Controls the electronic scorecard and print assets.
2
Configure scoring & side games

The event inherits settings from the league, but you can override anything here:

  • Scoring format (Net, Gross, Stableford, etc.)
  • Number of flights (A/B or single field)
  • Side games (Skins, CTP, Long Drive, Low Putts)
  • CTP hole numbers (which par-3s have a contest)
  • Custom competitions
  • Use Handicaps toggle
3
Shotgun start? (optional)

Toggle Shotgun Start if all groups tee off simultaneously from different holes. You'll assign a starting hole to each group in the Groups tab.

Leave off for sequential tee times (groups go off Hole 1 at intervals).

4
Add event details (optional)

Fill out any optional fields to enhance the public event page:

About this EventRich text description shown on the public page. Supports bold and italic.
ScheduleAdd check-in time, first tee, lunch, awards, etc.
SponsorsAdd sponsor names, logos, and website links.
Cover PhotoHero image shown at the top of the public event page.
Registration SpotsMax player count for online registration.
5
Save the event
Your event is created with Upcoming status. You'll activate it on the day of the round.
Step 4
Add Players to the Event
Players need to be added to each event individually. You can pull from your existing roster or add someone new on the spot.
1
📋 Event → Players tab → Add Player to Event
Select a player from your roster
Type a name to search your existing player list. If they're new, click + Create New Player and enter their details.
2
Enter handicap information

For each player added to the event:

Handicap Index *The player's official USGA handicap index (e.g. 14.2). Scorify calculates the course handicap automatically.
TeeWhich tee set they're playing from. Affects stroke index allocation.
Flight optionalA or B. Only appears if flights are enabled for the event.
Tip: If "Use Handicaps" is turned off for the event, handicap index is not required and course handicap won't be calculated.
3
Mark a scorekeeper per group (optional)

You can designate one player per group as the Scorekeeper (SK). They'll be responsible for entering scores for their group on the day of the event.

Non-scorekeeper players can still view the scorecard but cannot enter scores.

4
Add guest players

Select Guest as the player type for one-time players. Guests are excluded from season standings but are included in event scoring and payouts.

Step 5
Assign Groups & Tee Times
Group players into foursomes (or any size). Each group gets a unique code players use to access their digital scorecard on the course.
1
👥 Event → Groups tab
Drag players into groups
Players start in the Unassigned pool. Drag them into numbered groups or click Auto-Assign to let Scorify create balanced groups automatically.
2
Tee times (sequential start)

If you set a first tee time on the event, Scorify calculates each group's tee time automatically based on the interval you set (default: 10 minutes).

Group 1 = first tee time, Group 2 = first + 10 min, etc.

3
Starting holes (shotgun start)
If Shotgun Start is enabled, assign each group a starting hole. Groups tee off simultaneously — Scorify tracks which hole each group is on during scoring.
4
Generate group codes

Click Generate Codes. Each group gets a unique 5-character code (e.g. ALPHA, BRAVO). Players enter this code on their phone to access their scorecard.

Codes are printed on Cart Signs automatically.

Tip: Print Cart Signs after generating codes — one per group, placed in the golf cart on the day of the event.
5
Share the public event link

Send your players the public event URL before the round. They can view the event details, pairings, and access scoring on the day.

URL format: scorifygolf.com/[org]/[league]/[event]

Step 6 — Event Day
Running Digital Scoring
On the day of the event, activate the round and let players score hole-by-hole on their phones. The leaderboard updates in real time.
1
📍 Event → Overview → Start Event
Activate the event
Change the event status from Upcoming to Active. This enables live scoring and makes the leaderboard visible.
2
Players access their scorecard

Players open the event URL on their phone, tap Pairings, find their group code, then go to the scorecard URL or scan the QR code on the Cart Sign.

They'll be asked to enter their group code and select their name from the group list.

No account needed. Players don't need to sign up or log in — just the group code.
3
Scoring hole-by-hole

The scorecard shows one hole at a time. The scorekeeper enters each player's gross score, then taps Save & Next to advance to the next hole.

Net score and vs-par display updates automatically as scores are entered.

Tip: The scorecard works offline — scores are saved locally and synced when connection is restored. Great for courses with spotty signal.
4
Admin scoring (backup)
As an admin, you can enter or edit scores directly from Event → Groups → Edit Scores. This is useful if a group has trouble with their phone or prefers paper.
5
Monitor the live leaderboard

Share the leaderboard URL with anyone — it updates live as scores come in. No login required to view.

Display it on a TV or tablet at the clubhouse for everyone to follow along.

Step 7 — After the Round
Results & Payouts
After all scores are in, record side game winners and let Scorify calculate the final payout breakdown.
1
💰 Event → Payout tab
Review standings
The leaderboard is automatically ranked by your scoring format. Check that all scores are entered and correct before proceeding.
2
Enter prize amounts

For each scoring format and side game, enter the prize dollar amount. Scorify calculates the breakdown automatically based on the entry fee and player count — or you can override with custom amounts.

3
Record side game winners

For Skins — winners are calculated automatically from scores.

For CTP, Long Drive, and custom competitions — select the winner from the dropdown for each hole/contest. Enter the payout amount.

4
Review the payout summary
A complete breakdown shows total prize pool, winnings per player, and earnings by category. This doubles as a record for future reference.
5
Complete the event

Click Complete Event to lock scores and post final results. The status changes to Complete.

Final standings are preserved and visible on the public leaderboard permanently.

Note: You can still edit scores after completing an event if a correction is needed. Results update automatically.
Step 8
Print Assets
Scorify generates print-ready assets for your event. Print them before the round and place them in carts or at check-in.
📋
Tee Sheet
Full list of all groups with player names, tee times, and starting holes. Great for check-in or posting at the pro shop.
🪧
Cart Signs
One per group. Shows group number, players, tee time, starting hole, and the group code for digital scoring. Place in the golf cart.
📍
CTP Cards
One per designated CTP hole. Place at the tee box. Players record their distance to the pin on the card.
🏌️
Side Game Cards
Cards for Long Drive, custom competitions, and other side games. One per contest, placed at the relevant hole or check-in table.
🖨️ Event → Pre/Post Round tab → Print
Select which assets to print, then use your browser's print dialog (⌘P on Mac / Ctrl+P on Windows). Assets are formatted for standard letter paper. Make sure Background Graphics is enabled in print settings for full color output.
Club Plan Feature
Online Registration
Let players register for events online — collecting their info, questions, and payment confirmation — all without back-and-forth messages.
1
Enable registration on an event
In the event settings, toggle on Online Registration. Set the registration fee, max spots, and Venmo/PayPal handle for payment.
2
Add custom registration questions (optional)
Ask players anything during registration — shirt size, handicap index, meal preference, etc. Mark questions as required or optional.
3
Share the registration link
A Register button appears on the public event page. Players fill out the form and are directed to pay via Venmo or PayPal. You receive an email notification for each new registration.
4
Manage registrations

View all registrations in Event → Players → Registrations. Confirm payment manually, mark players as confirmed, and add them to the event player list with one click.

Pro Tips
Getting the Most Out of Scorify
📱
Test scoring before the round
Do a quick test run the day before — enter a group code, select a name, and try entering a score. Confirm it appears on the leaderboard.
📶
Offline mode works
Scores are saved locally when there's no signal and sync automatically when connection returns. No data is lost on spotty courses.
🖨️
Print Cart Signs the night before
Don't wait until the morning. Print and prep all assets the evening before so check-in runs smoothly.
✏️
Scores are always editable
Even after an event is completed, admins can correct any score. The leaderboard and payouts update instantly.
👤
Reuse your player roster
Players added once stay in your roster forever. For recurring events, just pull them from the roster — no re-entering info each time.
📺
Display leaderboard on a TV
Open the leaderboard URL on any device and display it at the clubhouse. It auto-refreshes — no one needs to do anything.
